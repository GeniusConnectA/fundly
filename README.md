# Fundly 💰

Fundly is a simple family money tracker designed to help users manage child accounts, balances, spending, received money, transactions, and receipts.

## Features

- 👤 Create and manage accounts
- 👨‍👩‍👧 Create child accounts
- 💰 Track balances
- ➕ Record money received
- ➖ Record spending
- 🧾 Generate receipts
- 🔍 Search transactions
- 🌙 Light and dark mode
- 💾 Local device storage
- 📱 Installable as a Progressive Web App (PWA)
- 📴 Works offline after installation

## Technology

Fundly is built with:

- HTML
- CSS
- JavaScript
- LocalStorage
- Progressive Web App (PWA)

## Important

Fundly is a personal/local money-tracking application. It is **not a bank, payment service, or financial institution**.

Data is stored locally on the device and is not automatically synchronized between devices.
